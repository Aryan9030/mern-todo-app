# 📝 MERN To-Do App

A simple and beautiful **Full-Stack To-Do Application** built with **React**, **Node.js**, and **Express**. Easily add, edit, complete, and delete your daily tasks with a stunning UI.

![To-Do App](https://img.shields.io/badge/Status-Completed-success)
![React](https://img.shields.io/badge/Frontend-React-blue)
![Node](https://img.shields.io/badge/Backend-Node.js-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as complete (checkbox)
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📊 Task Counter (Total / Pending / Done)
- 🎨 Beautiful gradient UI
- ⌨️ Press Enter to add tasks
- 🔗 Full-stack connection (Frontend ↔ Backend)

---

## 🛠️ Tech Stack

**Frontend:**
- ⚛️ React.js
- ⚡ Vite
- 🎨 CSS (Inline Styling)

**Backend:**
- 🟢 Node.js
- 🚂 Express.js
- 🌐 CORS
